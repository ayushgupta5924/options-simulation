# Options Trading Simulation

A cross-platform options pricing application using Monte Carlo simulation.

## Features
- Monte Carlo option pricing simulation
- Flutter mobile app with intuitive UI
- Python Flask API backend
- Real-time option price calculation

## Quick Start

### Flutter App
```bash
cd option_trading
flutter pub get
flutter run
```

### Python API
```bash
pip install -r requirements.txt
cd api
python main.py
```

## Usage
1. Enter stock parameters (price, strike, time, rate, volatility)
2. Run simulation to get option price and statistics
3. View results with confidence intervals

## Tech Stack
- Frontend: Flutter/Dart
- Backend: Python Flask
- Simulation: NumPy Monte Carlo methods
